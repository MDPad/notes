| Что                    | Для чего                      | Когда использовать         |
| ---------------------- | ----------------------------- | -------------------------- |
| **goroutine**          | параллельное выполнение       | всегда                     |
| **channel**            | передача данных / координация | поток данных, worker pool  |
| **unbuffered channel** | синхронизация                 | когда один ждёт другого    |
| **buffered channel**   | очередь                       | producer–consumer          |
| **mutex**              | защита общей памяти           | shared map/state           |
| **RWMutex**            | частые чтения                 | read-heavy данные          |
| **atomic**             | быстрый инкремент/флаг        | простой state              |
| **WaitGroup**          | дождаться горутин             | финализация/пулы           |
| **select**             | мультиплексирование событий   | таймауты, fan-in           |
| **context**            | отмена, таймаут               | сеть, API, долгие процессы |
