
| Характеристика      | Вытесняющая многозадачность (Preemptive multitasking) | Кооперативная (Cooperative multitasking)                   |
| ------------------- | ----------------------------------------------------- | ---------------------------------------------------------- |
| Кто управляет?      | ОС / планировщик                                      | Сам поток (или фреймворк)                                  |
| Безопасность        | Высокая (изолированы от залипания)                    | Низкая (если залипает задача, то она не отдаст управление) |
| Сложность отладки   | Высокая (race conditions)                             | Низкая, но баги часто логические                           |
| Контекст-свитчинг   | Есть (дороже)                                         | Минимальный (дешевле)                                      |
| Гибкость управления | Низкая (ОС решает)                                    | Высокая (ты сам решаешь когда yield)                       |

| Язык / среда         | Тип многозадачности                                         | Планировщик          |
| -------------------- | ----------------------------------------------------------- | -------------------- |
| C (`pthread`)        | Вытесняющая (preemptive), системные потоки                  | ОС                   |
| Java                 | Вытесняющая, системные потоки                               | ОС                   |
| Go                   | Гибрид: кооперативная + частичная вытесняемость             | Go runtime           |
| Python (`asyncio`)   | Кооперативная                                               | Event loop           |
| JavaScript (Node.js) | Кооперативная (через `async/await`, event loop)             | Event loop           |
| Kotlin coroutines    | Кооперативная, с возможностью preemption в suspend-позициях | Coroutine dispatcher |
| Erlang               | Кооперативная, green threads                                | BEAM VM              |
| Rust (`tokio`)       | Кооперативная (через `await`), иногда с runtime preemption  | Tokio runtime        |
