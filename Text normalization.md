https://unicode.org/reports/tr15/#Norm_Forms

| Норма    | Расшифровка                       | Что делает                                           | Пример (`é`)             | Пример (`⅓`)          |
| -------- | --------------------------------- | ---------------------------------------------------- | ------------------------ | --------------------- |
| **NFC**  | Normalization Form **C**omposed   | Склеивает **диакритику** обратно в составные символы | `é` → `é` (U+00E9)       | `⅓` → `⅓`             |
| **NFD**  | Normalization Form **D**ecomposed | Разбивает на **основу + акценты**                    | `é` → `e` + `́` (U+0301) | `⅓` → `1` + `⁄` + `3` |
| **NFKC** | Compatibility + Composition       | NFC + заменяет **стили и формы** (𝔸 → A, ① → 1)     | `é` → `é`                | `⅓` → `1/3`           |
| **NFKD** | Compatibility + Decomposed        | NFD + стили → base формы                             | `é` → `e` + `́`          | `⅓` → `1`, `/`, `3`   |

### Цели

| Цель                                 | Нормализация       |
| ------------------------------------ | ------------------ |
| Генерация текста с орфографией       | `NFC`              |
| Семантический поиск / эмбеддинги     | `NFKC`             |
| Классификация тем, тональности       | `NFKC`             |
| Сравнение текстов без учёта формы    | `NFKC + lowercase` |
| Лингвистический анализ               | `NFD`              |
| Обучение модели BPE с минимумом шума | `NFC` или `NFKC`   |


### Примеры на моделях

|Модель|Делает нормализацию?|Какую?|
|---|---|---|
|GPT-2/3/4|✅ Частично (по форме)|часто NFC|
|BERT|✅ Обязательно|NFC + lowercase|
|T5|✅ Обязательно|NFKC|
|SentencePiece|✅ по умолчанию|NFKC|
|Tokenizers HuggingFace|✅ configurable|NFC или NFKC|
