V3 - past participle

| Tense                                | Formula                        | Active                            | Passive                                      |
| ------------------------------------ | ------------------------------ | --------------------------------- | -------------------------------------------- |
| Present Simple                       | am/is/are + V3                 | Tom hoovers the carpet            | The carpet is hovered by Tom                 |
| Present Continuous                   | am/is/are + being + V3         | Tom is hoovering the carpet       | The carpet is being hoovered by Tom          |
| Present Perfect                      | has/have + been + V3           | Tom has hoovered the carpet       | The carpet has been hoovered by Tom          |
| Past Simple                          | was/were + V3                  | Tom hoovered the carpet           | The carpet was hoovered by Tom               |
| Past Continuous                      | was/were + being + V3          | Tom was hoovering the carpet      | The carpet was being hoovered by Tom         |
| Past Perfect                         | had + been + V3                | Tom had hoovered the carpet       | The carpet had been hoovered by Tom          |
| Future Simple                        | will + be + V3                 | Tom will hoover the carpet        | The carpet will be hoovered by Tom           |
| Future Continuous                    | am/is/are + be + being + V3    | Tom will be hoovering the carpet  | The carpet **will be being hoovered** by Tom |
| Future Perfect                       | will + have + been + V3        | Tom will have hoovered the carpet | The carpet will have been hoovered by Tom    |
| Future with “going to”               | am/is/are + going to + be + V3 | Tom is going to hoover the carpet | The carpet is going to be hoovered by Tom    |
| Modals (can, must, should, might...) | modal + be + V3                | Tom can hoover the carpet         | The carpet can be hoovered by Tom            |
|                                      |                                |                                   |                                              |
|                                      |                                |                                   |                                              |
